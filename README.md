# C++ Backend Service (CMakeProject3)

Консольное приложение на C++, демонстрирующее базовую архитектуру бэкенда: управление подключениями к базе данных SQLite и работу с сущностями пользователей.

## 🛠 Технологический стек

* **Язык программирования:** C++17 / C++20
* **Система сборки:** CMake (Ninja / MSVC)
* **База данных:** SQLite 3
* **Среда разработки:** Visual Studio 2022

## 📁 Структура проекта

```text
CMakeProject3/
├── CMakeLists.txt        # Сценарий сборки CMake
├── CMakePresets.json     # Пресеты конфигурации CMake
├── data/                 # Папка для локальной БД (database.db)
└── src/                  # Исходный код проекта
    ├── main.cpp          # Точка входа в приложение
    ├── database.h        # Объявление класса работы с SQLite (RAII)
    ├── database.cpp      # Реализация подключения и обработки ошибок БД
    ├── user.h            # Объявление модели пользователя User
    └── user.cpp          # Реализация бизнес-логики модели User
```

## 🚀 Сборка и запуск

### Visual Studio 2022 (Рекомендуется)

1. Откройте Visual Studio 2022.
2. Выберите **«Открытие локальной папки»** (Open a local folder) и укажите корневую директорию проекта.
3. Дождитесь автоматической генерации кэша CMake.
4. Выберите целевой объект `CMakeProject3.exe` и нажмите **F5** (с отладкой) или **Ctrl + F5** (без отладки).

### Консольная сборка через CMake

```bash
# Создание директории сборки и конфигурация
cmake -B build -S .

# Компиляция проекта
cmake --build build

# Запуск программы (Windows)
.\build\src\CMakeProject3.exe
```

## 💡 Особенности реализации

* **Безопасность ресурсов (RAII):** Управление подключением SQLite с корректным освобождением ресурсов и защитой от двойного закрытия.
* **Оптимизация памяти:** Использование move-семантики (`std::move`) при создании объектов и возврат константных ссылок (`const std::string&`) в геттерах.
* **Быстрая сборка:** Использование forward declaration (`struct sqlite3;`) в заголовочных файлах для уменьшения связности кода.
